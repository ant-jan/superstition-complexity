# superstition-complexity

Structured repository for materials related to the paper:

- `experiments/` — experiment code.
- `data/behavioral/raw/` — original behavioural dataset files.
- `data/behavioral/processed/` — cleaned/derived behavioural datasets.
- `analyses/behavioral/` — behavioural data analysis scripts and outputs.
- `simulations/` — simulation code.

## Suggested workflow

1. Place raw behavioural data in `data/behavioral/raw/`.
2. Save processed datasets in `data/behavioral/processed/`.
3. Keep experiment code in `experiments/`.
4. Keep analysis code in `analyses/behavioral/`.
5. Keep simulation code in `simulations/`.
